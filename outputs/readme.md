# outputs/

Everything generated by running the notebooks: figures, PDF reports, and (git-ignored) logs and
checkpoints.

- **`figures/`** — per-notebook PNG plots (`nb01`–`nb07`), 63 files total. See `figures/readme.md`.
- **`reports/`** — per-notebook LaTeX/PDF writeups (`nb01`–`nb07`) plus
  `lbsm_unified_report.{tex,pdf}`, which merges all seven into one document. See
  `reports/readme.md`.
- **`logs/`** — git-ignored, notebook-planning notes rather than execution logs (currently just
  `goal.md`, a research-questions scratch note for NB05).
- **`checkpoints/`** — git-ignored, currently empty/unused. Actual checkpoint state (the
  robustness grid's per-configuration fitting results) lives under `data/raw/nb07/checkpoints*`,
  not here.

Nothing under `figures/` or `reports/` is git-ignored — regenerate by re-running the corresponding
notebook if a file looks stale relative to `data/processed/`.
