# `datasets/`

Raw, unmodified real-world telemetry archives, downloaded from NASA's Planetary
Data System (PDS) for **NB08 — Real-World Generalization of LBSM**
(see `docs/NB08_REAL_WORLD_GENERALIZATION_PLAN.md`).

This directory is distinct from `data/`: `data/raw/` and `data/processed/` hold
artifacts *generated by the LBSM pipeline itself* (synthetic agent telemetry,
manifold embeddings, HMM output, etc.). `datasets/` holds external source data,
exactly as downloaded, that NB08 will parse into `data/raw/nb08/` — nothing here
has been read or transformed by any LBSM code yet.

---

## `eu/` — Mars Pathfinder rover engineering telemetry

**Correction from earlier planning notes**: this is *not* Pathfinder's
atmospheric/meteorology (ASI/MET) instrument — it is the **Sojourner
microrover's engineering telemetry**, confirmed directly from the PDS label
file (`DATA_SET_ID = "MPFR-M-RVRENG-2/3-EDR/RDR-V1.0"`,
`INSTRUMENT_NAME = "ROVER ENGINEERING SENSORS"`). If anything downstream
(including `docs/NB08_REAL_WORLD_GENERALIZATION_PLAN.md`) still calls this
"ASI/MET," that reference is stale and should be corrected to match.

If anything, this is a *closer* real-world analogue to LBSM's synthetic
adaptive-agent telemetry than weather data would have been: it's genuine
autonomous-rover health/behavioral telemetry (communication error counters,
command sequencing, health checks, startup-cause codes, motor/wheel fault
counts, battery/CPU/motor temperatures, heading), not an environmental signal.

**Layout**: one zip per Martian sol (day), `sol{NN}_eu.zip`, each containing a
matched triplet:
- `sol{NN}_eu.tab` — the PDS-formatted fixed-width data table
- `sol{NN}_eu.csv` — the same data, comma-separated (first 4 records are a
  spreadsheet-friendly header block)
- `sol{NN}_eu.lbl` — the PDS3 ODL label: authoritative column-by-column
  definitions (name, byte offset, unit, description) — **read this before
  writing any parser**, do not infer column meaning from the `.tab`/`.csv`
  alone

**Shape** (sol01, representative): 1294 rows x 385 columns. Column count and
row count vary per sol depending on how much telemetry was returned that day.

**Sol coverage**: 73 of sols 1-78 present. Missing: **10, 17, 45, 46, 55**
(not yet downloaded, or not present in the archive — not yet checked which).

**Git tracking**: `.gitignore` already excludes `datasets/eu/` (~15 MB) — these
files will not be committed.

**Official source**:
- PDS dataset profile: <https://pds.nasa.gov/ds-view/pds/viewProfile.jsp?dsid=MPFR-M-RVRENG-2/3-EDR/RDR-V1.0>
- PDS dataset view (URL-encoded form): <https://pds.nasa.gov/ds-view/pds/viewDataset.jsp?dsid=MPFR-M-RVRENG-2%2F3-EDR%2FRDR-V1.0>

## `rems_sol01_89/` — MSL (Curiosity) REMS environmental telemetry (TELRDR only)

Rover Environmental Monitoring Station data from Curiosity — REMS is the
instrument suite that measures **air temperature, ground temperature,
atmospheric pressure, wind, humidity, UV, and thermopile
readings**, plus its own sensor/electrical/thermal housekeeping channels.
This is the deliberately different second domain for NB08's cross-domain
generalization test: where `eu/` (Sojourner) is rover *engineering/operational*
telemetry, REMS is Curiosity's *environmental/instrument* telemetry — worth
preserving that distinction as-is when this gets written up, rather than
describing both as "rover engineering telemetry."

**Product scope — resolved and pruned to TELRDR only.** The PDS REMS RDR SIS
and dataset catalog (`MSL-M-REMS-3-TELRDR-V1.0`) define the processing chain:

```
EDR (raw ADC counts) -> RTL = TELRDR (electrical/thermal units)  <- what this directory holds
                      -> RNV = ENVRDR (environmental/physical units, derived from TELRDR)
                      -> RMD = MODRDR (corrected/modelled environmental units, derived from ENVRDR)
ADR = ancillary/processing data (separate, not part of this chain)
```

NB08 only needs TELRDR, so the `ADR`/`RMD`/`RNV` files that were originally
downloaded alongside `RTL` have been removed — this directory now holds only
`RME_<SCLK>RTL<sol>..._PA.TAB` files, one per sol. Per the SIS, each TELRDR
row is one acquisition session, with columns ordered: time references, Wind
Sensor, Ground Temperature Sensor, Air Temperature Sensor, UV Sensor,
Humidity Sensor, Pressure Sensor.

**Download in progress**: 6 complete sols (`SOL00001`, `SOL00009`-`SOL00013`),
~44 MB. `SOL00014`'s directory exists but is still empty (file not yet
downloaded). Directory name implies an eventual sol 1-89 range.

**Still to confirm before parsing**: no `.LBL`, `.xml`, or other
self-describing label file has been seen on disk yet (re-checked at time of
writing) — the SIS gives the column *order* above, but exact byte
offsets/units per column should still be confirmed against the SIS itself
(or a label file, if one ships alongside the `.TAB`s later) rather than
assumed from order alone.

**Git tracking**: `.gitignore` already excludes `datasets/rems_sol01_89/` — these
files will not be committed.

**Official source**:
- PDS Atmospheres node, REMS data page: <https://pds-atmospheres.nmsu.edu/data_and_services/atmospheres_data/MARS/curiosity/rems.html>

availability check — still open: confirm dated external reference events,
